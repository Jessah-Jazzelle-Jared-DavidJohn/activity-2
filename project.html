Team Development Projects

Project 1: Multi-Page HTML Website

Our first project is the creation of a multi-page website using HTML5 semantic elements. The website contains a home page, team information, schedule, projects, and contact page.

Project 2: Team Collaboration

Our team uses Git and GitHub to collaborate on the website. Each member works on an assigned page and submits their work through a feature branch and pull request.

Development Steps

  1. Plan the structure of the website.
  2. Assign pages to each team member.
  3. Create the HTML files.
  4. Write and validate the HTML code.
  5. Commit changes using Git.
  6. Push the feature branch to GitHub.
  7. Create a Pull Request.
  8. Review and merge the changes.
  9. Test all navigation links.
  10. Deploy the website using GitHub Pages.
